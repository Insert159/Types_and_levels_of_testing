# Чек-лист 

## 1. Поле ввода названия магазина (SC21-01)

- [ ] 1.1. Отображение плейсхолдера. В пустом поле отображается плейсхолдер.
- [ ] 1.2. Исчезновение плейсхолдера. Плейсхолдер исчезает при начале ввода.
- [ ] 1.3. Минимальная длина. Кнопка «Поиск» не активируется/поиск не запускается при вводе менее 2 символов.
- [ ] 1.4. Ввод «любых» символов. Поле принимает и отображает: цифры, латиницу, кириллицу, спецсимволы (`!@#$%`), эмодзи, пробелы.
<br>Добавлено ИИ
- [ ] 1.5. Обработка пробелов. Поиск срабатывает корректно (или обрезается) при вводе пробелов в начале/конце или нескольких пробелов подряд.
- [ ] 1.6. Предельная длина. Ввод 256 и более символов не приводит к вылету/зависанию приложения, поле не обрезается некорректно.
- [ ] 1.7. Сохранение истории. После выполнения поиска введённое значение сохраняется.
- [ ] 1.8. Отображение истории. При повторном клике/фокусе на поле отображается список предыдущих поисков.
- [ ] 1.9. Выбор из истории. Выбор значения из истории приводит к копированию его в поле и автоматическому поиску (или активации кнопки «Поиск»).

---

## 2. Поле выбора типа магазина (SC21-02)

- [ ] 2.1. Отображение плейсхолдера. В невыбранном состоянии отображается плейсхолдер «Выберите тип магазина».
- [ ] 2.2. Тип элемента управления. Поле является выпадающим списком (dropdown).
- [ ] 2.3. Состав списка. В списке присутствуют минимум три варианта: «Продуктовые магазины», «Магазины стройматериалов», «Аптеки».
<br>Добавлено ИИ
- [ ] 2.4. Выбор значения. При клике по элементу списка он выбирается и отображается в поле.
- [ ] 2.5. Отображение выбранного. Плейсхолдер заменяется на выбранное значение.

---

## 3. Кнопка «Поиск» (SC21-03)

- [ ] 3.1. Активность (валидный сценарий). Кнопка активна, если введено ≥2 символов в поле «Название» И/ИЛИ выбран тип магазина.
- [ ] 3.2. Активность (невалидный сценарий). Кнопка НЕ активна (серая, не нажимается), если поле «Название» пустое или <2 символов И тип магазина не выбран.
- [ ] 3.3. Дизайн. Внешний вид (цвет, форма, размер) кнопки соответствует макету/гайдам.
<br>Добавлено ИИ
- [ ] 3.4. Отображение результатов (название). При поиске по названию найденные магазины отображаются в виде флажков на карте.
- [ ] 3.5. Отображение результатов (тип). При поиске по типу найденные магазины (все или ближайшие) отображаются флажками.
- [ ] 3.6. Отображение результатов (оба поля). При указании названия И типа результаты соответствуют критериям: магазины с таким названием И с таким типом.
- [ ] 3.7. Скролл карты. После отображения результатов карту можно скроллить (менять видимую область).
- [ ] 3.8. Зум карты. После отображения результатов карту можно зумировать (приближать/отдалять).

---

## 4. Кнопка «Построить маршрут» (SC21-04)

- [ ] 4.1. Активность (по названию). Кнопка активна, когда найден результат по названию И пользователь выбрал флаг нужного магазина.
- [ ] 4.2. Активность (по типу). Кнопка активна, когда выбран тип магазина (без требования выбирать флаг).
- [ ] 4.3. Дизайн (исходное состояние). Кнопка содержит иконку «изогнутая стрелка», надпись «Построить маршрут», белый фон (#fff).
<br>Добавлено ИИ
- [ ] 4.4. Корректность маршрута (название). Маршрут строится до ТОГО магазина, чей флаг был выбран.
- [ ] 4.5. Корректность маршрута (тип). Маршрут строится до БЛИЖАЙШЕГО магазина выбранного типа.

---

## 5. Отмена маршрута (SC21-04, SC21-05)

- [ ] 5.1. Надпись после построения. После построения маршрута кнопка имеет надпись «Отменить маршрут».
- [ ] 5.2. Отмена кликом. При нажатии на кнопку с надписью «Отменить маршрут» построенный маршрут с карты исчезает.
<br>Добавлено ИИ
- [ ] 5.3. Возврат состояния кнопки. После отмены маршрута кнопка возвращается к виду «Построить маршрут» (иконка, белый фон).
- [ ] 5.4. Отмена только кнопкой. Попытка отменить маршрут другим способом (например, очисткой полей, новым поиском) не приводит к исчезновению линии маршрута.

---

## 6. Область карты (SC21-05)

- [ ] 6.1. Размер карты. Область карты занимает ровно половину видимой области экрана телефона.

---

## 7. Сценарии невалидного ввода и ошибок (по ТЗ не описано, но критично)

- [ ] 7.1. Поиск без результатов. Если по введённому названию или типу ничего не найдено, приложение должно показать понятное сообщение («Ничего не найдено»), а не оставлять пользователя в непонимании.
<br>Добавлено ИИ 
- [ ] 7.2. Нет доступа к GPS. Если геолокация отключена, приложение должно запросить разрешение или показать ошибку с инструкцией.

---

## 8. Общие требования (SC21-06)

- [ ] 8.1. Повторное открытие. При закрытии и повторном открытии приложения, если маршрут не был отменён, он отображается снова на карте.
<br>Добавлено ИИ
- [ ] 8.2. Энергосбережение. При снижении заряда аккумулятора ниже указанного в ТЗ порога (предположим, 20%) приложение должно отключить точную геопозицию (перестать обновлять местоположение в реальном времени).
- [ ] 8.3. Восстановление геопозиции. При подключении зарядки или поднятии заряда выше порога приложение должно вернуть точную геопозицию.
