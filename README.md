# Виды и уровни тестирования

Проект по классификации тестирования и тестированию документации

## О проекте

В проекте изучены виды и уровни тестирования, их применение на разных этапах разработки. Освоено тестирование документации по критериям полноты, однозначности, непересекаемости и атомарности. Применены методики Black-box и Grey-box для составления чек-листов.

## Что выполнено

📋 **Задание 1. Классификация тестирования**

Заполнена таблица категоризации видов тестирования для мобильного банковского приложения. Для каждой категории указаны примеры: альфа-тестирование, бета-тестирование, smoke-тестирование, Black-box, Grey-box, позитивное/негативное тестирование, статическое и динамическое.

🏗️ **Задание 2. Уровни тестирования**

Составлена таблица по уровням: модульное, интеграционное, системное, приемочное тестирование. Для каждого уровня указано: что проверяем, кем проводится, артефакты, примеры дефектов.

📄 **Задание 3. Тестирование документации**

Проведен анализ технического задания для приложения Найди и иди. Выявлены ошибки по критериям: полнота, однозначность, атомарность, непересекаемость. Выполнено сравнение с анализом ИИ.

⚫ **Задание 4. Black-box**

На основе проанализированного ТЗ составлен чек-лист проверок приложения по методике Black-box (без знания внутреннего устройства). Выполнено сравнение с ИИ-генерацией и объединение лучших идей.

🔘 **Задание 5. Grey-box**

С учетом доступа к базе данных магазинов составлен чек-лист по методике Grey-box. Проанализирована и доработана ИИ-генерация с уточнением контекста.

## Технологии и темы

| Техника/Тема | Описание |
|--------------|----------|
| Виды тестирования | По стадии, знанию системы, направленности, выполнению кода |
| Уровни тестирования | Модульное, интеграционное, системное, приемочное |
| Тестирование документации | Критерии: полнота, однозначность, атомарность, непересекаемость |
| Black-box | Тестирование на основе требований, без знания кода |
| Grey-box | Тестирование с частичным знанием внутреннего устройства (БД) |
